# 03 — Control Flow

Branching and loops.

## Goals

- `if` / `else if` / `else`.
- Classic `switch` statement and modern `switch` expression with arrow syntax (Java 14+).
- `for`, `while`, `do-while`.
- Enhanced `for` (for-each) over arrays/collections.
- `break` and `continue`.

## Tasks

1. Write a grader: input score → return `A`, `B`, `C`, `D`, `F`.
2. Re-implement the grader using a `switch` expression on a range or category.
3. Print numbers 1–10 with `for`. Skip multiples of 3 using `continue`.
4. Use `while` to find the first power of 2 greater than 1000.
5. Print a 5×5 multiplication grid using nested `for`.

## Run

```bash
java src/03-control-flow/Main.java
```
