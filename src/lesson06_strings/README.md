# 06 — Strings

`String` is immutable. `StringBuilder` is mutable.

## Goals

- Common methods: `length`, `charAt`, `substring`, `indexOf`, `contains`, `replace`, `toUpperCase`, `toLowerCase`, `trim`, `split`.
- `String.format` and `printf`.
- Text blocks (`"""..."""`).
- `String.join`.
- `StringBuilder` for efficient concatenation in loops.
- `equals` vs `==` (value vs reference).

## Tasks

1. Take a sentence, count the words (split by whitespace).
2. Reverse a string using `StringBuilder.reverse()`.
3. Check if a string is a palindrome (ignore case).
4. Format a multi-line block using a text block.
5. Compare two strings — first with `==`, then `.equals` — explain the difference in a comment.
