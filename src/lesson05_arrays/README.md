# 05 — Arrays

Fixed-size, indexed sequences.

## Goals

- Declare and initialize: `int[] a = {1, 2, 3};` and `new int[5]`.
- Access by index, get `.length`.
- Iterate with classic `for` and for-each.
- 2D arrays.
- `java.util.Arrays` helpers: `sort`, `toString`, `copyOf`, `fill`.

## Tasks

1. Create an `int[]` of 5 numbers. Print sum, min, max.
2. Reverse the array in place.
3. Sort a copy using `Arrays.sort` and print with `Arrays.toString`.
4. Build a 3×3 `int[][]` and print it as a grid.
5. Make a `String[]` and join it with `String.join(", ", arr)`.

## Run

```bash
cd src
javac lesson05_arrays/Main.java
java lesson05_arrays.Main
```
